# Интеграция с ReportPortal

### Развернуть собственный локальный сервер ReportPortal.
1. Проверить соответствие характеристик локальной машины предъявляемым требованиям:
   - CPU: минимум 2 ядра.
   - RAM: минимум 6 ГБ оперативной памяти (инстанс не запустится или будет падать по OOM, если выделить меньше).
   - Диск: от 20 ГБ свободного места.
2. Скачать конфигурационный файл с https://raw.githubusercontent.com/reportportal/reportportal/master/docker-compose.yml
3. Создать файл docker-compose.yml в корневой папке проекта и заполнить его скачанным содержимым.
4. Настроить пароль администратора:
   - найти в файле пароль (возможно, строка 503) и заменить его:
   - services:
            uat:
               environment:
                  - RP_INITIAL_ADMIN_PASSWORD=Пароль_123
5. Запустить сборку командой: docker compose -p reportportal up -d --force-recreate
